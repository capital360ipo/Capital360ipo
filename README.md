# Capital360IPO

Starter website for IPO, stock-market and financial news.

## GitHub upload
Extract this ZIP first. Upload the CONTENTS of the extracted folder to the root of your GitHub repository. `package.json` and the `app` folder must be visible at the repository root.

## Vercel
Import the GitHub repository. Framework should be Next.js. Add environment variables from `.env.example` in Project Settings before connecting Supabase features.

This is a starter template, not a finished financial-data service. Verify all IPO, GMP, stock and news information with reliable sources. GMP is unofficial and speculative. Not investment advice.
